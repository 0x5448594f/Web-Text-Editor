To facilitate writing articles on my [journey website](), I create a small text editor to write directly in Markdown and convert it in HTML at the end. So, I can copy past the HTML and gain a lot of time of creating the article.

# 🌟 Highlights

The editor contain a lot of features who can upgrade the ergonomie of the website and the usage to the user like: 

 - [x] - Automatic Convert Markdown to HMTL to realtime preview. <br/>
 - [x] - Modify a line by just clicking on it, like Word or Google Doc <br/>
 - [x] - Buttons ( bold, italic... ) for people who don't know some markdown prefix <br/>
 - [x] - Adding image <br />
 - [ ] - Copy the HTML in the clipboard by clicking in a button <br/>
